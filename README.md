# Media Collection  
  Sistema Web gratuito para a catalogação de coleções de filmes em mídia física. <br> <br/>

## Sobre o Projeto:
  * O Media Collection visa ampliar a cultura do colecionismo, sobretudo da mídia em disco, com a criação de um sistema efetivo de catalogação de grandes bibliotecas de filmes. 
  
  * O projeto engloba o desenvolvimento de um sistema web que permitirá a catalogação de grandes coleções de filmes, tanto em DVD quanto Blu-ray, permitindo que o usuário visualize o histórico do crescimento de sua biblioteca, o valor pago por sua coleção, assim como identificar padrões de seu consumo via gráficos como, por exemplo, quais são os gêneros e anos de lançamento mais comuns, métricas atualmente não presentes nos sistemas mais utilizados. 
  
  * O catálogo de filmes é cadastrado e acessado utilizando a API ‘The Movie Database’, que permite o acesso efetivo a todo o banco de dados do conteúdo cadastrado no IMDB assim como os lançamentos em mídia física destes filmes.
